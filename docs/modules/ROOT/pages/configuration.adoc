= Configuration

Configuration is loaded by `onecx_pipecat.config.Settings`, a
`pydantic-settings` model with the environment prefix `ONECX_`.
Nested fields use `__` as the delimiter, so:

[source,shell]
----
SERVER_PORT=9000
ONECX_AUTH__ISSUER=https://issuer.example
ONECX_SPEECH__STT_PROVIDER=aws
ONECX_PERMISSION__VOICE_RESOURCE=VOICE
----

== Reference

[cols="25,20,55",options="header"]
|===
| Field | Default | Description

| `app_name`
| `onecx-pipecat`
| Display name of the application.

| `host`
| `127.0.0.1`
| Bind address for the HTTP server.

| `port`
| `8080`
| Port for the HTTP server. Read from `SERVER_PORT` (or `ONECX_PORT`).

| `log_level`
| `INFO`
| Application log level.

| `default_tenant_id`
| `local`
| Tenant identifier used when a request does not carry one.

| `auth.server_url`
| (empty)
| Keycloak base URL. Read from `KEYCLOAK_SERVER_URL` (or `ONECX_AUTH__SERVER_URL`).

| `auth.realm`
| (empty)
| Keycloak realm. Read from `KEYCLOAK_REALM` (or `ONECX_AUTH__REALM`).

| `auth.issuer`
| `https://auth.example`
| When `auth.server_url` and `auth.realm` are set and no issuer is configured,
derived as `{server_url}/realms/{realm}`. Expected JWT issuer, validated by `JwtAuthAdapter` when verifying the
`apm_principal_token` carried in `start_session`.

| `auth.token_claim_subject`
| `sub`
| JWT claim name read as the authenticated subject.

| `auth.jwks`
| (empty)
| Keycloak JWKS used to verify the `apm_principal_token` carried in
`start_session`: an embedded `keys` document as a JSON string, or a URL.
Empty fetches `{auth.issuer}/protocol/openid-connect/certs`. The set is
refetched when a token carries an unknown `kid` (at most once a minute).

| `auth.client_id`
| `onecx-pipecat`
| Read from `KEYCLOAK_CLIENT_ID` (or `ONECX_AUTH__CLIENT_ID`). Client identifier of Pipecat's own OIDC client-credentials grant; the
resulting token is sent as `Authorization: Bearer` to ai-provider, chat, and
permission services (never to MCP servers).

| `auth.client_secret`
| (empty)
| Read from `KEYCLOAK_CLIENT_SECRET` (or `ONECX_AUTH__CLIENT_SECRET`). Client secret for Pipecat's OIDC client-credentials grant.

| `auth.token_endpoint`
| (empty)
| OIDC token endpoint for the client-credentials grant. Empty uses
`{auth.issuer}/protocol/openid-connect/token`.

| `agent_config.default_agent_id`
| `onecx-agent`
| Default agent to pin when no override is present.

| `agent_config.default_snapshot_version`
| `1`
| Default snapshot version to pin.

| `agent_config.base_url`
| `http://onecx-ai-provider-svc:8080`
| Base URL of onecx-ai-provider-svc; `HttpAgentConfigAdapter` calls
`GET /v1/agents/{id}/configuration` once per session.

| `chat.base_url`
| `http://onecx-chat-svc:8080`
| Base URL of onecx-chat-svc; `HttpChatAdapter` calls
`GET /internal/chats/{id}` to load the chat as the user.

| `chat.history_max_messages`
| `50`
| Newest chat messages (`GET /internal/chats/{id}/messages`) loaded into the
LLM context at session start.

| `speech.stt_provider`
| `inmemory`
| STT provider identifier.

| `speech.tts_provider`
| `inmemory`
| TTS provider identifier.

| `speech.sample_rate_hz`
| `16000`
| Expected audio sample rate in hertz.

| `speech.turn_detection`
| `vad`
| Who detects user turns: `vad` (server-side Silero VAD; the client only
streams audio) or `client` (push-to-talk via `user_started_speaking` /
`user_stopped_speaking`).

| `speech.region`
| `us-east-1`
| AWS region the Transcribe and Polly profiles live in (`aws` provider only).

| `speech.default_language`
| `en`
| Fallback language when the pinned agent configuration does not specify one.
A pinned language that is not configured in `speech.aws_profiles` is
unsupported and produces a typed `unsupported_language` error.

| `speech.aws_profiles`
| `en` -> `{transcribe_language: "en-US", polly_voice: "Joanna"}`
| Map of language code to its AWS speech profile, read only when the `aws`
provider is selected. Each profile pairs an AWS Transcribe language code
(`transcribe_language`) with an Amazon Polly voice (`polly_voice`, default
`Joanna`), so one pinned language maps to both the STT and TTS deployments.

| `persistence.backend`
| `chat`
| `chat` saves voice turns to onecx-chat-svc and loads the chat history
(`HttpChatPersistence`); `inmemory` is for tests and local development.

| `persistence.max_entries_per_session`
| `512`
| Soft cap on entries kept per session (`inmemory` backend only).

| `permission.base_url`
| `http://onecx-permission-svc:8080`
| Base URL of onecx-permission-svc; `HttpPermissionAdapter` calls
`POST /v1/permissions/user/{productName}/{appId}` to check the user's voice
permission.

| `permission.voice_product_name`
| `onecx-chat`
| `productName` of the application that owns the voice permission.

| `permission.voice_app_id`
| `onecx-chat-ui`
| `appId` of the application that owns the voice permission.

| `permission.voice_resource`
| `VOICE`
| `resource` of the OneCX permission that grants voice.

| `permission.voice_action`
| `USE`
| `action` of the OneCX permission that grants voice.

| `mcp.timeout_seconds`
| `30.0`
| HTTP timeout for MCP calls. MCP server URLs are *not* configured here: they
come from each agent's configuration (`mcpServers[].url`).

| `credentials.refs`
| `{}`
| JSON map of `credentialRef` -> secret (`ONECX_CREDENTIALS__REFS`), e.g.
`{"credential://provider/p1/api-key": "sk-..."}`. The LLM provider's
`credentialRef` from the agent configuration is looked up here; an unknown or
blank reference fails the session start closed (`config_unavailable`). Values
are `SecretStr`: never logged, exposed by `/healthz`, or sent to the client.

|===

== LLM provider mapping

The pinned agent configuration selects the LLM (`provider` + `model`). A
configuration without a supported `provider.type` or with a blank
`model.modelIdentifier` is rejected at session start.

[cols="15,85",options="header"]
|===
| `provider.type` | Pipecat service

| `OPENAI`
| `OpenAILLMService`. API key from `credentialRef` (when `authMode` is
`API_KEY`); `llmUrl` becomes `base_url`, so OpenAI-compatible endpoints work
(a key is optional when `llmUrl` is set).

| `OLLAMA`
| `OLLamaLLMService` with `llmUrl` as `base_url`. Credentials are ignored
(Pipecat sends a fixed placeholder key).

| `ANTHROPIC`
| `AnthropicLLMService`. API key from `credentialRef` is required; `llmUrl`
overrides the API base URL.
|===

`authMode=OAUTH` is not supported. `model.modelConfig` (a JSON object string)
maps to service settings for `temperature`, `max_tokens`/`maxTokens` and
`top_p`/`topP`; other keys are ignored and invalid JSON fails the start.

Scaffold skills (entries with a name and instruction) are advertised in the
system prompt and exposed through the `activate_skill(name)` function.

== Real and in-memory adapters

The OneCX boundaries — authentication, agent configuration, chat, permission,
and MCP — always use their real adapter (`JwtAuthAdapter`,
`HttpAgentConfigAdapter`, `HttpChatAdapter`, `HttpPermissionAdapter`,
`HttpMcpAdapter`). There is no in-memory fallback a deployment could silently
run on: a token that cannot be verified against the issuer's JWKS, or a
service call whose client-credentials token cannot be obtained, fails closed.

Speech defaults to deterministic in-memory Pipecat services because no
deployment has selected the `aws` provider yet. Selecting
`stt_provider`/`tts_provider` to `aws` builds Pipecat's AWS Transcribe and
Polly services per session from `speech.region`, `speech.default_language`, and
`speech.aws_profiles`. The agent's own LLM provider is always used; only
tests and local development may set `ONECX_LLM__PROVIDER_OVERRIDE=inmemory`.
`persistence.max_entries_per_session` is enforced by `InMemoryPersistence`,
which is used only with `ONECX_PERSISTENCE__BACKEND=inmemory`.

Not yet read by any adapter: `agent_config.default_agent_id` and
`agent_config.default_snapshot_version`.

== Precedence

Explicit constructor kwargs > environment variables > the defaults
declared on the model. `pydantic-settings` handles this precedence for you.
